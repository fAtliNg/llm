# Журнал решений и открытые вопросы

## Принятые решения

| Дата | Решение | Причина |
|------|---------|---------|
| 2026-09-14 | Размер модели: класс 7–8B | Влезает в Q4 на M2 Pro 16 ГБ и RTX 4070 Super 12 ГБ, доступно широкому кругу пользователей |
| 2026-09-14 | Метод обучения: LoRA, инструмент Unsloth | Одна карта 24 ГБ, десятки долларов за прогон, простой вход |
| 2026-09-14 | Обучение на арендованной GPU | Локального железа для обучения нет |
| 2026-09-14 | Бенчмарк и выбор инструмента делаются до датасета | Формат данных должен совпадать с форматом запросов инструмента; бенчмарк это отложенная выборка |
| 2026-09-14 | Эксперимент сравнивает четыре конфигурации: база/файнтюн × без обвязки/с обвязкой | Нужно отделить эффект обучения от эффекта шаблона и документации в контексте |
| 2026-09-14 | Финальный замер на Q4 GGUF, не только на bf16 | Квантизация может съесть часть эффекта файнтюна |
| 2026-09-14 | Начинаем с чистого листа, старый скелет `lvc` удалён | Проект перестраивается от документов и бенчмарка; скелет остаётся в истории git (коммит `6a7d83b`) |
| 2026-09-14 | Стили: MUI на Emotion, без styled-components | MUI + styled-components это редкая конфигурация с двумя рантаймами, базовая модель знает её плохо |
| 2026-09-14 | Сборка: Vite | CRA мёртв, Next.js тащит SSR и слишком большую поверхность для 8B |
| 2026-09-14 | Тесты: Vitest (следствие выбора Vite) | Общий конфиг с Vite, без ts-jest и babel. Для модели разница с Jest минимальна: `vi.fn` вместо `jest.fn` |

## Стек

### Поверхность знания для модели

На это идёт датасет.

| Роль | Выбор | Мажорная версия |
|------|-------|-----------------|
| UI | React | 19 |
| Язык | TypeScript | 5 |
| Компоненты и стили | MUI на Emotion, `styled` и `sx` | 7 |
| Данные и стор | Redux Toolkit + RTK Query | 2 |
| Формы | react-hook-form + zod | 7 + 4 |
| Роутинг | React Router, режим библиотеки | 7 |

### Инфраструктура

Присутствует в каждом примере неявно, служит верификатором.

| Роль | Выбор |
|------|-------|
| Сборка | Vite 7 |
| Тесты | Vitest + React Testing Library + MSW 2 |
| Качество | ESLint + Prettier, `strict: true`, без `any` |

Точные минорные версии фиксируются через `npm view` в момент создания шаблона проекта.

### Измеримые различия версий

Библиотеки, где базовые модели тянут старый API. Ровно тот эффект, который файнтюн должен показать на бенчмарке.

| Библиотека | Что поменялось | Что пишет базовая модель |
|---|---|---|
| Zod 4 | `z.email()` вместо `z.string().email()`, новая система ошибок | Zod 3 |
| MUI v7 | Grid с пропом `size` вместо `xs/md` | Grid v5 |
| React 19 | `ref` как обычный проп, без `forwardRef` | `forwardRef` |
| React Router 7 | Импорт из `react-router`, не `react-router-dom` | v6 |
| RTK 2 | Новые сигнатуры, `combineSlices` | RTK 1 |
| MSW 2 | `http.get` и `HttpResponse` вместо `rest.get` и `res(ctx.json())` | MSW 1 |

## Известные проблемы стека

1. **Лицензия на выход модели-учителя.** Условия Claude и OpenAI запрещают обучать конкурирующие модели на их выходе. Для публичного релиза датасет генерировать открытой моделью (большой Qwen3-Coder, DeepSeek) через Together или на арендованной GPU.
2. **Учитель тоже не знает новых версий.** При генерации давать документацию в контексте; верификация через tsc это единственный фильтр мусора, а не дополнение.
3. **MUI слишком большой.** Нужен белый список из 20–30 компонентов для CRUD-приложений. Всё вне списка модель знает хуже, это принимаемое ограничение.
4. **MUI плохо тестируется в jsdom.** Select это кнопка с listbox, Dialog рендерится в портал. Тесты бенчмарка должны быть устойчивыми, иначе измеряем хрупкость тестов, а не модель.
5. **У каждой связки несколько правильных способов.** RHF через `register` или `Controller`, роутер через `createBrowserRouter` или `<Routes>`, тест RTK Query с реальным стором или с моком. Модель учится одному способу. Шаблон содержит эталон каждого паттерна, датасет генерируется от него. Список канонических паттернов это отдельный документ.
6. **Длина примеров.** Задача с контекстом из 3–4 файлов шаблона это 4–8 тысяч токенов. LoRA на 24 ГБ такое тянет, 16k уже впритык. Решить, сколько контекста класть в обучающий пример.
