Задачам нужна необязательная дата выполнения. Пользователь выбирает её в форме задачи в поле даты с подписью "Due date" и видит в таблице задач в колонке "Due"; у задач без даты там стоит "—". Храним как `dueDate`: ISO-строка даты вида `2026-12-31` или null, через весь стек: контракт, база с миграцией, API и веб-приложение. API должен отклонять значение, которое не является корректной датой. Существующие задачи продолжают работать. Обнови существующие тесты там, где этого требует изменение.
