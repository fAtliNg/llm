Сотрудников можно создавать, но нельзя менять. Добавь в каждую строку таблицы сотрудников ссылку "Edit" (accessible name "Edit <name>"), которая открывает `/employees/:employeeId/edit`: страница с заголовком "Edit employee", формой, заполненной значениями сотрудника, и кнопкой "Save", после которой пользователь возвращается к списку. Для неизвестного id показывается "Employee not found".

Добавь в каждую строку кнопку "Delete" (accessible name "Delete <name>") с диалогом подтверждения с заголовком "Delete employee?", так же, как удаляются задачи; после подтверждения сотрудник пропадает из списка.

Когда API отвечает 409, потому что email принадлежит другому сотруднику, оставайся на форме и покажи под полем Email сообщение от API: "An employee with this email already exists". На странице создания то же самое. API уже умеет всё необходимое. Добавь тесты.
