Баг: ESLint не требует фигурные скобки вокруг тел `if`, `else`, `for` и `while`. Нужно включить правило `curly` с опцией `all`, чтобы `npm run lint` падал на `if (x) return;`. Исправить все существующие нарушения. Проверить, что правило действительно срабатывает: в текущей структуре конфига легко добавить его в место, где оно не будет иметь эффекта.
