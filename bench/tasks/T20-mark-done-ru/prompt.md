Пользователи хотят закрывать задачу прямо из списка. Для каждой незавершённой задачи добавь в её строку кнопку "Mark done" (accessible name "Mark done <title>", как у кнопки удаления). По клику статус задачи меняется на done через API, и в строке появляется бейдж Done. У уже завершённых задач такой кнопки нет.
