Задачам нужны метки. У задачи может быть любое число коротких текстовых меток (например "frontend", "urgent"). В форме задачи пользователь вводит их в поле "Labels" через запятую; в таблице у каждой задачи метки показываются бейджами рядом с названием. Задачи, мок-данные и вызовы API без меток продолжают работать, а мок-API валидирует метки как любое другое поле. Обнови существующие тесты, если это потребуется.
