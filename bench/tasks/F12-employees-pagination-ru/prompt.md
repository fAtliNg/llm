Компания выросла, а страница сотрудников загружает всех сразу. Сделай пагинацию на сервере.

`GET /api/employees` теперь возвращает одну страницу: `{ "items": [...], "total": <число всех сотрудников>, "page": <n>, "pageSize": <n> }`, с сортировкой по имени. Он принимает `page` (1 или больше, по умолчанию 1) и `pageSize` (от 1 до 50, по умолчанию 10); на всё остальное отвечает 400 с `{ "message": "Invalid pagination" }`. Страница за концом списка возвращает пустой `items` с правильным `total`. Используй SQL limit, offset и count, а не загрузку всех строк. Схему ответа положи рядом с контрактом в `shared/employees.ts`.

На странице показывай по десять сотрудников с переключателем страниц под таблицей: текст "Page 1 of 3" между кнопками "Previous" и "Next", которые отключены на первой и на последней странице. После создания сотрудника список и число страниц обновляются без перезагрузки. Обнови существующие тесты там, где этого требует изменение, и добавь тесты с обеих сторон.
