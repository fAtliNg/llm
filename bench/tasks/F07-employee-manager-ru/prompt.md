Мы хотим видеть, кто кому подчиняется. У каждого сотрудника может быть руководитель, и это другой сотрудник.

Добавь сотрудникам `managerId` через весь стек: id другого сотрудника или null. В сидах второй сотрудник подчиняется первому. В форме сотрудника появляется селект с подписью "Manager", где по умолчанию выбрано "No manager", а остальные варианты это существующие сотрудники по именам. В таблице сотрудников появляется колонка "Manager" с именем руководителя или "—".

API не должен сохранять ерунду: `managerId`, которого нет среди сотрудников, даёт 400 с `{ "message": "Unknown manager" }`, а PATCH, который делает сотрудника руководителем самого себя, даёт 400 с `{ "message": "An employee cannot manage themselves" }`. Удаление руководителя должно по-прежнему работать: его подчинённые просто остаются без руководителя (`managerId` становится null).
