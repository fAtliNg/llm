Пользователи хотят сужать список задач по статусу. Добавь над таблицей на странице задач фильтр: селект с подписью "Filter by status", в котором по умолчанию выбран пункт "All", плюс по пункту на каждый статус. При выборе статуса в таблице остаются только подходящие задачи, "All" снова показывает всё.
