# Все прогоны бенчмарка по задачам, 2026-09-20

Строка — задача, столбец — модель и машина, на которой она запускалась. Пустая ячейка: задача на этой модели и машине не запускалась.

Ячейка, сверху вниз:
1. ✅ решена хотя бы в одной попытке / ❌ ни разу; **решено из попыток**.
2. **скр.** — доля пройденных скрытых тестов, среднее по попыткам (нет строки — скрытые тесты не запускались, обычно проект не собирался).
3. **Чем кончились неудачи** (×N — сколько попыток): ⏱ таймаут; 🛑 лимит ходов; модель сама закончила, но: **ТС** ошибки типов, **ПВ** поведение не совпало со скрытыми тестами, **СТ** сломала существующие тесты, **Л** линт, **Ф** форматирование, **С** структура проекта, **СлТ** слабые свои тесты; **API** сбой вызова модели (у локальных моделей — обрыв ответа Ollama).
4. Среднее по попыткам: **х.** ходов агента, **мин** минут.

Машины: **ПК** — RTX 4070 Super, Docker; **сервер 4090** — арендованная RTX 4090, три агента делили карту (условия строже KPI, ход около 18 с против 13 с у одного агента на ПК); **сервер** на v1 — арендованный сервер первых замеров; **Mac** — M-серия 16 ГБ; **API** — облачная модель, обвязка на Mac.
