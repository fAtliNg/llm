# Обучение на арендованном GPU

Нужны три файла из этой папки: `run.sh`, `train.py` и `../bench/dataset/train.jsonl` (скопировать сюда как `train.jsonl`).

## RunPod, пошагово

1. runpod.io → Pods → Deploy. Карта: **A100 SXM 80 GB** (Community Cloud, около 1,6 $/ч) или H100 (3,3 $/ч, вдвое быстрее). Шаблон: **RunPod PyTorch** последней версии (CUDA 12.8+). Диск контейнера 60 ГБ, volume 60 ГБ: базовая модель 19 ГБ, слитая 19 ГБ, GGUF 6 + 10 ГБ.
2. Дождаться статуса Running, открыть **Connect → Jupyter Lab** (или Web Terminal).
3. Загрузить три файла в `/workspace` через кнопку upload в Jupyter (train.jsonl 22 МБ).
4. В терминале:
   ```bash
   cd /workspace && bash run.sh smoke
   ```
   Около 10 минут: ставит библиотеки, скачивает базовую модель, делает 20 шагов. В конце в логе `train_runtime` и секунды на шаг. Полный прогон это примерно 200 шагов (800 примеров × 2 эпохи / 8) × секунды на шаг. Если что-то падает, чинить здесь, деньги ещё не потрачены.
5. Полный прогон:
   ```bash
   bash run.sh full
   ```
   Ожидание 1,5–3 часа. Можно закрыть браузер: скрипт пишет `train.log`, `tail -f train.log` показывает прогресс.
6. Скачать `out/v1/gguf-q4_k_m.tar` (около 6 ГБ) и `out/v1/lora` (адаптер, 200 МБ, на всякий случай) через Jupyter или `runpodctl`.
7. **Stop → Terminate** pod. Пока pod остановлен, но не удалён, тарифицируется только диск (центы в час).

Оплата посекундная, только за время работы pod. Прогон целиком 4–6 долларов.

## На Mac после скачивания

```bash
tar -xf gguf-q4_k_m.tar
ollama create qwen3.5-9b-agent:v1-q4 -f Modelfile   # путь к .gguf внутри Modelfile
ollama run qwen3.5-9b-agent:v1-q4 "hi"
```

Затем конфигурации `ft-harness` и `ft-bare` в бенчмарке указывают на эту модель.

## Переменные

- `MAX_SEQ=16384 bash run.sh full` для карты на 48 ГБ (длинные примеры отбрасываются).
- `OUT=out/v2` для следующей версии.
