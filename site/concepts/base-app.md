# The base app

React 19 (Vite), Hono API, SQLite with Drizzle, RTK Query, zod, Vitest, and the whole shadcn/ui set in `src/components/ui`. The typeface is Inter (variable, self-hosted).

## Colours

Colours and typography are not in CSS but in `meta/themes/` (see [Theme](/objects/theme)). The base app ships `light` and `dark` with the VitePress default palette and type, so an app built from meta looks like a documentation site out of the box. Edit a theme file to re-skin every page at once.
