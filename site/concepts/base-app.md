# The base app

React 19 (Vite), Hono API, SQLite with Drizzle, RTK Query, zod, Vitest, and the whole shadcn/ui set in `src/components/ui`.

## Colours

The theme variables in `src/index.css` follow the VitePress default theme, so an app built from meta looks like a documentation site out of the box: brand `#3451b2`, page `#ffffff`, alternate surfaces `#f6f6f7`, text `rgb(60 60 67)`; in dark mode page `#1b1b1f`, surfaces `#161618`, text `rgba(255 255 245 / 0.86)`, brand `#a8b1ff`. The `dark` class on `<html>` switches; the built-in `theme` field toggles it. Change the variables to re-skin every page at once.
